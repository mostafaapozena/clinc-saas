# القرارات والعوائق

يجمع هذا الملف القرارات المطلوبة من المالك والجهات الخارجية في مكان واحد. الرموز القديمة (B، Q، E، D) هي نفسها في `DECISIONS.md` و`ERP_DECISIONS.md` و`PLATFORM_REMAINING_GAPS_AR.md`، ولم تُعَد تسميتها. البنود الجديدة رمزها `D-NEW-n`.

**«متى»:**

| القيمة | المعنى |
| --- | --- |
| **الآن** | الانتظار طويل، أو تعتمد عليه مرحلة قريبة |
| **قبل المرحلة n** | لا يلزم قبل ذلك |
| **قبل التجربة / الإنتاج** | بوابة جاهزية |

## 6. ما يمكن تنفيذه بالكامل دون أي قرار

- كل مهام المرحلة 1 (`P1-01`..`P1-13`)، ما عدا `P1-09` التي تحتاج الافتراض D-NEW-3 فقط.
- `P2-01` (سجل التخصصات)، و`P2-04` (التركيز حسب الفرع، بالافتراض D-NEW-4)، و`P2-05` و`P2-06` (مركز الإعداد والإطار)، و`P2-08`.
- `P4B-04` (عارض التدقيق)، و`P4B-05` (التصدير)، و`P4B-06` (رحلات متصفح).

## 7. عوائق خارجية قائمة

| العائق | الأثر | المالك |
| --- | --- | --- |
| لا مراجعين أطباء | لا اعتماد سريري، ولا تجربة بسجلات حقيقية | المالك |
| لا محاسب مراجع | لا استخدام محاسبي حقيقي، ولا قيود جديدة في المرحلة 4 | المالك |
| لا استضافة | لا نشر، ولا نسخ مجدول، ولا مراقبة، ولا اختبار اختراق | المالك + الميزانية |
| لا مستشار قانوني | لا نصوص معتمدة، ولا سياسة احتفاظ | المالك |
| لا مزوّد بريد | لا استعادة كلمة مرور ولا دعوات خارج التطوير | المالك |
