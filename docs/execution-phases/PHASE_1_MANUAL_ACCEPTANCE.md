## 1. الدخول والتنقل (بلوحة المفاتيح وقارئ الشاشة)

| # | الخطوات | النتيجة المتوقعة | النتيجة | ملاحظات |

| 1.2 | أدخل كلمة مرور خاطئة واضغط `Enter` | تُقرأ رسالة الخطأ دون أن تتحرك إليها بنفسك، ويبقى البريد كما كتبته | | |
| 1.3 | ادخل بحساب المالك. اضغط `Tab` مرة واحدة، ثم تابع حتى الشريط الجانبي | أول محطة رابط «تخطَّ إلى المحتوى». كل رابط في الشريط يُقرأ باسمه، والصفحة الحالية تُعلن «الصفحة الحالية». حلقة التركيز ظاهرة دائمًا | | |
| 1.4 | انتقل إلى «المواعيد» ثم «التقارير» | عند فتح صفحة يُقرأ عنوانها (h1). المحتوى لا يُختصر ولا يتداخل | | |

## 5. التكبير الفعلي 200%

| # | الخطوات | النتيجة المتوقعة | النتيجة | ملاحظات |
| --- | --- | --- | --- | --- |
| 5.1 | Chrome بنافذة كاملة (1366 أو أعرض). اضغط `Ctrl` و`+` حتى 200%. افتح الرئيسية | لا تمرير أفقي للصفحة. القائمة الجانبية تصير زر قائمة | | |
| 5.2 | بالتكبير نفسه: التقارير، والمواعيد، والإعدادات، والخزينة، بالعربية ثم بالإنجليزية | لا نص مقطوع ولا متداخل، والأزرار كلها في متناول اليد | | |

## 6. إدخال التاريخ العربي وفهمه

**الفرق المطلوب ملاحظته:**
- **حقل التاريخ نفسه** أداة المتصفح. شكله وترتيبه (يوم/شهر أو شهر/يوم) يتبعان **لغة المتصفح أو النظام**، لا لغة raclinic. متصفح بالإنجليزية الأمريكية يعرض 4 مارس كـ `03/04/2026` حتى والصفحة بالعربية.
- **السطر تحت الحقل** من raclinic. يكتب اليوم الذي فهمه التطبيق باسم الشهر واسم اليوم، بلغة الواجهة (مثل «الأربعاء، 4 مارس 2026»)، فلا يبقى لبس.
- **التواريخ المعروضة** في الجداول والتقارير من raclinic أيضًا، والشهر فيها باسمه.

| # | الخطوات | النتيجة المتوقعة | النتيجة | ملاحظات |
| --- | --- | --- | --- | --- |
| 6.1 | المواعيد: اختر من حقل التاريخ يوم 4 مارس | يظهر بجانب الحقل «الأربعاء، 4 مارس 2026»، والمواعيد المعروضة لذلك اليوم | | |
| 6.2 | اكتب التاريخ بلوحة المفاتيح بدل المنتقي | السطر يتغير مع كل تاريخ كامل ويطابق ما قصدته | | |
| 6.3 | سجّل لغة المتصفح والنظام كما هي، ولاحظ ترتيب الحقل (يوم/شهر أو شهر/يوم) | الترتيب قد يختلف، والسطر تحت الحقل يحسم المعنى | | |
| 6.4 | أي نموذج فيه تاريخ (فاتورة مورد، أو تسوية، أو تقرير بتاريخ) | السطر نفسه تحت كل حقل تاريخ مكتمل | | |
| 6.5 | مع قارئ الشاشة على حقل التاريخ | بعد التاريخ يُقرأ السطر الوصفي (اليوم والشهر باسميهما) | | |
| 6.6 | زر «English» أعلى الصفحة (أو الملف الشخصي ← اللغة)، ثم كرر 6.1 | السطر بالإنجليزية («Wednesday, March 4, 2026») | | |

**القرار:** يبقى منتقي التاريخ الأصلي (لوحة مفاتيح، وجوال، وقارئ شاشة). لا يُستبدل بمكوّن مخصص إلا إذا أظهر هذا الفحص مشكلة استخدام لا يحلها السطر الوصفي.
