# Front-end audit response (2026-10-27)

This document answers a browser audit of the development preview. The audit was run with
Claude in Chrome by the owner on 27 Oct 2026.

**What the audit covered**

- **Roles tested:** owner (Nour clinic) and platform admin.
- **Views:** desktop about 1150px wide, and an emulated mobile view 390px wide.
- **Not tested:** the other roles. The Codespace stopped on its idle timeout and the preview returned 502.

**Result:** 56 findings. None was Critical, 1 was High, 19 Medium and 36 Low.

The table below records, for each finding:

- what changed;
- or why nothing changed;
- or which decision it waits on.

The **Tests** column lists the test that covers the change: an API test (`api/`) or a web test.

**Status values**

- **Fixed:** changed and covered by a test, or by `npm run verify` for style-only changes.
- **Partly:** the main problem is fixed and a remainder is listed.
- **No change:** not a defect of the app, with the reason given.
- **Owner:** a product or commercial decision that is not ours to make.
- **Open:** a real issue that was not done in this pass.

## Preview environment (not an app defect)

**Symptom:** the private preview at `…-5173.app.github.dev` returned 502 while the dev server
answered inside the Codespace.

**Observations**

- The Codespaces agent created a forward for port 5173 only while a VS Code session was attached.
  At other times one of the forwarded ports had no host-side listener.
- After the Codespace stops on its idle timeout, `/tmp` and the dev servers are gone.

**To restart the preview,** start the dev servers with `npm run dev` inside the Codespace. Vite
listens on `0.0.0.0:5173`.

Ports stay private.
